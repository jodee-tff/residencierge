# The Residencierge course page, for the Exec Hub

One file: `residencierge-hub.html`. It is the complete course companion site, self-contained (the only external calls are Google Fonts, with fallbacks), so it can be dropped into the Hub as a static page or an iframe target as-is.

- All fifteen pages are inside it (Home, Module 0 setup, every built lesson, Module 3 roped off) with hash routing, so deep links like `#/1-2` work.
- The clone prompt on page 0.2 is live and correct.
- When the course changes, Jodee re-exports this file and pushes it here; replace the old copy, nothing else to wire up.
